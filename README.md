项目名称：生物信息科研知识问答 Agent 助手 核心成员 2026.03-2026.06
技术栈：Python、FastAPI、Claude、DeepSeek Compatible API、Redis、ChromaDB、Docker
项目简介：基于 LLM 的生物信息科研知识问答平台，集成细粒度意图识别、意图触发的RAG知识增强、结构化主辅 Agent 路由、动态 Skills 注入、mcp 工具（miRNA-drug 关联预测，输入药物返回 Top-N miRNA，或查询指定药物-miRNA 的关联分数等工具、fetch-web 信息、生成测试报告）、Redis + ChromaDB 三级记忆、和 LLM-as-Judge 端到端评测，为生物信息科研知识问答提供服务。

1. 细粒度意图识别：结合 LLM Few-shot 语义理解、Embedding 相似度和 Pattern 关键词匹配三路融合识别意图，对用户请求进行意图分类和实体抽取，支持知识问答、关联预测、转人工等细分类。
2. 任务规划：内置任务清单机制，将"请求解析 -> MCP 工具调用 -> 校验预测结果  -> RAG 查询基础机制 -> 报告生成" 拆分为具备依赖关系的子任务，并维护 pending、in_progress、completed、failed 等状态。
3. RAG 检索优化：针对复杂模期查询，将查询拆分并改写为多角度子查询，并行召回ChromaDB 向量知识库中的相关文档，根据内容哈希和相似度进行合并去重，并由 LLM 实现召回结果重排。
4. Memory: 设计基于Redis+ChromaDB的分层记亿：使用异步 Redis 管理当前会话工作记忆、任务计划和中间结果，ChromaDB存储历史对话摘要和用户研究偏好。对 ChromaDB 等同步向量库操作放入线程池执行，降低记忆读写对主链路的阻塞影响。
5. 安全沙箱：基于 OpenSandBox 研发“主机+沙箱”双层文件访问平面，实现网络、进程及文件系统隔离，对代码脚本执行、Skill 调用等高风险动作进行沙箱隔离。
6. 链路追踪：在模型调用、工具调用、文件读写、任务状态变更等节点注入 Hook，支持缓存、重试、权限校验、敏感操作拦截和审计上报。
